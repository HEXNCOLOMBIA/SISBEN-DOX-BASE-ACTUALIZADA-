# 🕷️ SISBEN DOX –BUSQUDA AUTOMATIZADA 🕷️

**BY ORC ORGANIZACION**

---

## 🧠 Descripción

**SISBEN DOX** es un sistema de consultas por terminal desarrollado en **Python**, con una interfaz
Está diseñado para ejecutarse de forma Facil sin configuraciones complejas ni pasos innecesarios.  
Todo el proceso se realiza en  la terminal  priorizando velocidad, claridad y control del usuario.

---

## 🚀 Características

- Menú interactivo en consola  
- Consulta por documentos colombianos 
- Resultados mostrados en **un solo bloque**  
- Detección automática de datos faltantes  
- Campos vacíos marcados como **NO DISPONIBLE**  
- Compatible con **PC y Termux (Android)**  

---

## 📦 Requisitos

- Python **3.8 o superior**  
- Conexión a Internet  

---

## 🛠 Instalación

**Windows / Linux**

```bash
git clone https://github.com/HEXNCOLOMBIA/SISBEN-DOX-BASE-ACTUALIZADA-.git
cd SISBEN-DOX-BASE-ACTUALIZADA-
python sisben.py
```

**Termux (Android)**

```bash
pkg update -y
pkg install python git -y
git clone https://github.com/HEXNCOLOMBIA/SISBEN-DOX-BASE-ACTUALIZADA-.git
cd SISBEN-DOX-BASE-ACTUALIZADA-
python sisben.py
```
**actualizar repositorio en caso de que haga actualizaciones**

```bash
git pull
python sisben.py
```

---

## 🧭 Uso

Al iniciar el sistema aparecerá un menú en consola:

```
1 → Consulta por Cédula
0 → Salir
```

El sistema pedirá el dato correspondiente y mostrará el resultado completo en pantalla.

---

## 📊 Resultados

- Los datos se muestran en un solo bloque
- Campos vacíos se marcan como **NO DISPONIBLE**
- Se listan los campos faltantes al final
- Se indica si la consulta fue exitosa ✅
